1. RESUMEN EJECUTIVO
Este documento presenta el informe actualizado al 05 de enero de 2026 del proyecto de desarrollo del Sistema de Gestión de Inventario "ControlInventarioPRO", implementado utilizando la metodología ágil Scrum con arquitectura Spring Boot y patrón MVC en Java Web.
1.1 Objetivos del Proyecto
●	Digitalizar el control de entradas y salidas de mercancía
●	Implementar un control de acceso seguro mediante roles (Administrador/Empleado)
●	Facilitar la gestión de productos, proveedores y categorías en tiempo real
●	Generar reportes de stock mínimo, movimientos y análisis de proveedores
●	Optimizar la experiencia de usuario mediante interfaces intuitivas y responsivas

2. CONTEXTO DEL PROYECTO
2.1 Problema Identificado
La gestión actual de inventarios en muchas PYMES se realiza de forma manual o mediante hojas de cálculo desconectadas, generando:
●	⏱️ Pérdida de tiempo en conteos manuales
●	⚠️ Inconsistencia de datos y duplicidad de registros
●	🔒 Falta de seguridad en el acceso a información sensible
●	📉 Incapacidad para detectar robos hormiga o pérdidas de stock en tiempo real
●	📊 Ausencia de métricas y reportes para toma de decisiones
2.2 Solución Propuesta
Se desarrolló una aplicación web empresarial utilizando Spring Boot que permite:
●	🔐 Login seguro con gestión de sesiones y roles
●	📦 CRUD completo de productos, categorías y proveedores
●	📊 Dashboard interactivo con métricas en tiempo real
●	📈 Sistema de reportes en Excel y visualizaciones gráficas
●	🎨 Interfaz moderna y responsiva usando Bootstrap 5
●	🗄️ Base de datos relacional centralizada en MySQL
●	🔗 Relaciones entre entidades (Productos-Proveedores)

5.2 Arquitectura del Sistema
El sistema implementa el patrón MVC (Modelo-Vista-Controlador) con Spring Boot:
 Componentes Principales:
1.	Vista (JSP): Interfaz de usuario con Bootstrap 5
2.	Controlador (Spring Controllers): Procesa peticiones HTTP y coordina flujo
3.	Servicio (Service Layer): Lógica de negocio y transacciones
4.	Repositorio (Spring Data JPA): Acceso a datos con abstracción ORM
5.	Modelo (Entities): Entidades JPA mapeadas a tablas
